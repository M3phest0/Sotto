# Sotto v2.0

Windows 11 桌面便签组件：便签贴在桌面层，显示待办与番茄；编辑器负责增删改、设置与数据管理。

## 运行（开发）

```bash
./start-dev.sh
```

首次启动会编译 Rust 依赖（约 5–10 分钟），之后秒开。`env/` 是项目内虚拟环境（Rust 工具链 + cargo 缓存 + pnpm shim），不写系统目录。

## 构建发布版

```bash
./build-release.sh
```

产物在 `src-tauri/target/release/bundle/nsis/`，整理后的安装包/便携版见 `release/Sotto_v2.0/`。

## 功能

- 便签：桌面层（Win+D 后仍可见）、拖动记忆位置、滚轮浏览、勾选完成、单击任务打开编辑器并定位
- 番茄：逐颗显示；左键 +1 / 右键 −1（动画 + 音效）；顶部显示今日总数
- 编辑器：`Ctrl+Alt+E` 打开，`Ctrl+W` / `Esc` 收起；↑↓ 选择、Shift+↑↓ 多选、Delete 删除、F2 改标题、Ctrl+N 新建；任务详情与 DDL；拖拽排序；进行中/已完成分区
- 统计：编辑器"统计"页——今天/昨天对比、本周/上周 7 天柱状图、本周按任务投入排行
- 设置：主题三色自定义、便签宽高、音效开关/音量/自定义音频、快捷键、开机自启、导出导入、打开数据目录
- 数据：`%APPDATA%\Sotto\data.json`，番茄按 `{ taskId, ts }` 时间戳记录，每天自动备份 7 份
- 托盘：打开编辑界面 / 设置 / 开机自启 / 退出
- 单实例、200% DPI 适配

## 已知限制

- 仅单显示器
- 无隐藏快捷键、无自动计时番茄

## 开发脚本（可选）

`scripts/` 里是调试用的 PowerShell 脚本（截图、点击、DPI 诊断、图标生成），不影响应用本身。删除整个目录也不影响运行。
