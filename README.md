# Sotto 0.0.2

Windows 11 桌面便签组件（Demo）。便签贴在桌面层，显示待办与番茄数；编辑器负责增删改、设置与统计数据的记录。

## 运行

```bash
./start-dev.sh
```

首次启动会编译 Rust 依赖（约 5–10 分钟），之后秒开。`env/` 是项目内虚拟环境（Rust 工具链 + cargo 缓存 + pnpm shim），不写系统目录。

## 当前实现

- 便签：桌面层（Win+D 后仍可见）、拖动记忆位置、滚轮浏览、勾选完成、单击任务打开编辑器并定位、🍅 左键 +1 / 右键 −1（动画 + 音效）
- 编辑器：`Ctrl+Alt+E` 打开，`Ctrl+W` / `Esc` 收起；↑↓ 选择、Shift+↑↓ 多选、Delete 删除、F2 改标题、Ctrl+N 新建；任务详情与 DDL；列表拖拽排序
- 设置：主题三色自定义、便签宽高、音效开关/音量/自定义音频、快捷键、开机自启、导出导入
- 数据：`%APPDATA%\Sotto\data.json`，番茄按 `{ taskId, ts }` 时间戳记录，每天自动备份 7 份
- 托盘：打开编辑界面 / 设置 / 开机自启 / 退出

## 已知问题 / Demo 注意事项

- 旧版 Sotto（`E:\share\Claude\Win11桌面便签组件`）如果还在运行，会占用 `Ctrl+Alt+E`，新便签的快捷键会注册失败（日志里能看到 `HotKey already registered`）。先退出旧版即可。
- 统计图只记录了带时间戳的番茄事件，界面还没画。
- 托盘菜单、自定义音效、主题自定义已接好，但只做了基本人工验证。
- 多显示器、隐藏快捷键、自动计时番茄、安装包都未做。
